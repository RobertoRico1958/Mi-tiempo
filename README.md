# Mi tiempo, mis decisiones

Proyecto de investigación de 14 días para Matemáticas I (primero de secundaria).

## Publicación en GitHub Pages
1. Crea un repositorio público nuevo en GitHub.
2. Sube `index.html` a la raíz del repositorio (Add file > Upload files > Commit changes).
3. En Settings > Pages, elige Deploy from a branch, `main` y `/ (root)`; guarda.
4. Abre la dirección que GitHub muestre en Pages, generalmente `https://USUARIO.github.io/REPOSITORIO/`.

## Información importante
Los datos se conservan **en el navegador de cada equipo**, no en GitHub ni sincronizados entre dispositivos. Exporta un CSV regularmente y no registres nombres completos ni información privada de menores. La puntuación es educativa, no clínica.
